One sentence, in a house cat's own voice, defending itself in the five
seconds after sweeping a glass off the table. No apology, no confession —
just the most convincing case a cat can make for itself.

## Entry

> That glass had been judging my life choices all morning, so I removed the judge.

80 characters, one sentence, 15 words.

## How it works

`main.py` is a stdlib-only program: it copies the pre-written `entry.txt`
into `MAKEFUN_OUTPUT_DIR` (default `output/`) byte for byte. It fetches
nothing and generates nothing at run time, so the output is identical on
every run.
